# SunSafety-UV-Awareness-Protection-Platform

SUNSAFE – SMART UV SAFETY PLATFORM

A MERN-based smart UV awareness system that provides real-time UV index detection, safety recommendations, exposure time calculation, and UV trend visualization through a clean and interactive user interface.

📌 Project Overview
Ultraviolet (UV) radiation poses harmful risks such as sunburn, skin aging, eye damage, and cancer. However, most people lack real-time UV awareness.

SUNSAFE solves this problem by offering:
Real-time UV index detection using geolocation
UV risk classification with color-coded indicators
Interactive dashboard with hourly & weekly UV insights
Safe exposure time calculator
Sun-safety recommendations and tips
MongoDB storage for long-term UV history
Clean UI built with React + Vite + Tailwind + ShadCN
This project is fully built using the MERN stack (MongoDB, Express, React, Node.js), demonstrating scalable full-stack development.

🚀 Tech Stack
Layer	Technology Used
Frontend	React (Vite), TypeScript, TailwindCSS, ShadCN UI
Backend	Node.js, Express.js
Database	MongoDB Atlas, Mongoose
Icons	Lucide React
Tools	VS Code, Thunder Client/Postman

🌍 Features

🔸 Real-Time UV Detection
Auto-detects user location
Fetches UV index and displays risk level
Stores each reading in MongoDB

🔸 Interactive UV Dashboard
Hourly UV visualization
Weekly UV trend analysis
Color-coded bars for easy understanding

🔸 Exposure Calculator
Inputs: skin type, UV intensity
Outputs: safe sun exposure time
Reapplication reminders

🔸 Sun Safety Tips
SPF recommendations
Protective clothing suggestions
Hydration and shade guidance
